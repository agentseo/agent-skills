# Общий чек-лист по диффу

Запускай только пункты, чьё условие совпало с диффом или с тем, что выкачено. Формат:
**условие** → проверка. *Почему* — промах, из-за которого пункт появился.

Проектные пункты — в `CHECKS.md` проекта, не здесь. Раз в месяц: пункт ни разу не сработал и
не нужен — удалить.

## Деплой

- **Любой деплой** → цель — dev или прод из раздела «Деплой», не локальная копия; после выкладки
  файлы на сервере совпадают с локальными (md5 или `rsync --itemize-changes` пустой).
  *Почему:* «задеплоил» оказывалось выкладкой только в локальную копию.
- **Деплой через `rsync --delete`** → серверные файлы вне репозитория (статика, демо, файлы
  верификации) перечислены в исключениях до запуска. *Почему:* `--delete` стирает их молча.
- **Прод** → бэкап (БД и/или изменяемых файлов) сделан до выкладки, путь к нему есть в отчёте.

## Фронтенд

- **CSS/JS за CDN или кэширующим прокси** (Cloudflare и т. п.) → версия в URL ассета (`?v=`)
  поднята во всех страницах, которые его подключают; проверка с выключенным кэшем.
  *Почему:* новый HTML загрузился со старым закэшированным CSS и сломал страницу.
- **Тёмные блоки, цвета, `::selection`** → выделение текста видно на тёмном фоне; контраст текста ≥ 4.5:1.
- **Плавающие элементы, кнопки, виджеты** → новый элемент не перекрывает виджет чата, кнопку
  записи или cookie-плашку на 390 px.
- **Новая запись в списке с фильтрами** (кейс, услуга, товар) → запись видна в списке и в каждом
  фильтре, куда должна попасть. *Почему:* новый кейс не попал в фильтр по отрасли.

## Формы и почта

- **Формы, обработчики заявок** → отправка проходит, payload содержит все поля, ответ успешный;
  письмо или уведомление доходит (на проде — по правилу «боевые формы» в SKILL.md).
- **Отправка почты** → через SMTP с авторизацией, не `mail()`/sendmail. *Почему:* коды
  регистрации не доходили, письма уходили через sendmail.

## Аналитика

- **Шаблоны страниц, `<head>`, теги** → контейнер GTM / счётчик загружается на изменённых
  страницах; цели и события не сломаны. *Почему:* вывод «виджета нет» делался по HTML, а он
  подключён через GTM — смотри контейнер, а не только исходник страницы.

## Код

- **PHP** → не прогонять через prettier; `php -l` на изменённых файлах.
- **JSON / YAML данных** → файл парсится; для импорта — dry-run импорта проходит.
- **Python** → `py_compile` и тесты модуля, который правил.
