# FEATURES.md — шаблон

Кладётся в корень проекта. Сценарии — с точки зрения посетителя, коротко. Это и путеводитель
для проверки, и критерий «готово». `[всегда]` — прогоняется после каждого деплоя на прод.

```markdown
# FEATURES — <сайт>

Адреса: prod <https://…>, dev <https://… или «нет»>. Smoke: `<команда или «нет»>`.

## Главная  [всегда]
- `/` → 200; hero виден; кнопка «<текст>» (`<селектор>`) открывает <что>.

## Заявка  [всегда]
- `<путь формы>`: поля <список>; отправка → <ответ/страница благодарности>;
  запрос `POST <endpoint>` с полями <…>. На проде — mock, настоящая заявка только по просьбе.

## Список с фильтрами
- `/<список>` → карточки видны; фильтр «<имя>» (`<селектор>`) оставляет только <…>.

## Аналитика  [всегда]
- GTM `<GTM-XXXX>` / Метрика `<id>` грузится на всех страницах; цель «<имя>» срабатывает на <действии>.

## Виджеты
- Чат / запись / cookie-плашка: виден на 390 и 1440 px, ничем не перекрыт.
```

Заполняет агент при первой проверке проекта: по коду, живому сайту и разделу «Деплой».
Непроверенное в шаблоне помечай `(?)`. Показать diff владельцу до записи.
