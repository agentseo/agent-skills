# ship — деплой с проверкой

Скилл общий; адреса, хосты, команды и запреты — в разделе «Деплой» `AGENTS.md` проекта.
Глобальные правила (`~/.agents/AGENTS.md`: «Deploy ends on production», чужой проект → «yes, go
ahead», SSH — одна попытка) действуют поверх этого скилла.

## 0. Раздел «Деплой» есть?

Нет — не угадывай. Собери факты только чтением (репозиторий, история git, живой сайт; на сервер —
одна попытка по SSH, только чтение и только с разрешения), заполни раздел по шаблону
`references/deploy-section-template.md`, покажи владельцу diff и дождись «ок». Потом деплой.
Источники в проекте могут быть устаревшими — то, что легко проверить на живом сайте (версия CMS,
адрес dev), проверь.

## Порядок

1. **`git status`.** Незакоммиченное, не относящееся к задаче, — не выкатывать; спросить.
   Секреты, `.env`, личные файлы в выкладку не попадают.
2. **Бэкап** того, что перезапишется (БД и/или файлы) — по способу из раздела «Деплой». Путь в отчёт.
3. **Выкладка.** Есть dev → сначала dev. Длинная команда → скрипт-файл (на сервере в
   `~/.agent-tmp`, не в `/tmp`), без вложенных heredoc.
4. **`verify`** на этом окружении (скилл `verify`).
5. **Есть dev:** ссылки на изменённые dev-страницы владельцу → **стоп до его «ок»** → прод → `verify` на проде.
   **Нет dev:** сразу прод (после бэкапа) → `verify`.
6. **Провал на проде** после трёх кругов исправлений → откат из бэкапа шага 2 только если провал
   ломает сайт для посетителей; иначе стоп и отчёт. Откат — тоже в отчёт.
7. **Коммит** изменённых файлов с описанием по-русски и строкой
   `Verified: <что проверено, где>` (например `Verified: smoke+playwright prod`); если проверки не
   было — `Verified: none` и почему. Пуш — если так принято в проекте или владелец сказал.
8. **Отчёт по-русски:** что выкачено, ссылки на изменённые прод-страницы, бэкап, хеш коммита,
   что не проверено.

## Чего не делать без вопроса

nginx, симлинки, права на системные каталоги, `robots.txt`, удаление старых файлов из docroot,
переустановка CMS или миграции, стирающие данные. Конкретный список — в разделе «Деплой».
